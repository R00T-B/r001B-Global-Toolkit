# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | ✅ |
| 1.0.x   | ❌ |

## Reporting Vulnerabilities

**⚠️ Important**: This tool is for authorized penetration testing only.

If you find a vulnerability in the toolkit itself:

1. **Do not exploit** without permission
2. **Report responsibly** to security@r001b.com
3. **Provide details** including:
   - Vulnerability description
   - Steps to reproduce
   - Potential impact

## Safe Usage Guidelines

- 🔒 Use only on authorized systems
- 📜 Follow local laws and regulations  
- 🛡️ Implement proper auditing and logging
- 🔐 Secure sensitive data and reports
