## 📦 Quick Start

### Prerequisites
- Kali Linux 2023.x or newer
- Python 3.8+
- Root privileges (for some modules)

### Installation

```bash
# Clone the repository
git clone https://github.com/R00T-B/r001B-Global-Toolkit.git
cd r001B-Global-Toolkit

# Run setup script
chmod +x setup.sh
./setup.sh

# Launch toolkit
python3 src/main.py
